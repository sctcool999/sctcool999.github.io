約 350 BC
古代
亞里斯多德
Aristotle
運動理論 / 地心說 / 自然運動與強制運動
地心說：地球為宇宙中心，太陽、月亮、行星與恆星皆繞地球做完美圓周運動，天體鑲嵌於水晶球層上。
自然運動（natural motion）：物體回歸其「自然位置」的運動，無需外力。土與水天然向下，火與空氣天然向上，天體天然做圓周運動。
強制運動（violent motion）：違背自然位置、需要持續施力才能維持的運動（如推動石塊）。力一旦撤除，運動即停止。
落體理論：重物比輕物落得快，速度與重量成正比。
✗ 已推翻
地心說被哥白尼 / 伽利略 / 克卜勒推翻；落體理論被伽利略自由落體實驗推翻；「力維持運動」被牛頓慣性定律推翻；自然/強制運動框架被近代力學整體取代
約 150 AD
古代
托勒密
Claudius Ptolemy
地心說數學化（本輪 / 均輪模型）
《天文學大成》將亞里斯多德地心說數學化，引入本輪（epicycle）與均輪（deferent）機制，能預測行星位置，主導西方天文學約 1400 年。
 ✗ 已推翻
哥白尼（1543）日心說取代；克卜勒橢圓軌道定律提供更簡潔精確的模型
約 250 BC
古代
阿基米德
Archimedes
浮力原理 / 槓桿原理
浸入流體的物體所受浮力等於排開流體的重量（阿基米德原理）。槓桿：F₁d₁ = F₂d₂。靜力學基礎。
 ✓ 仍有效
完全成立，流體力學與靜力學基礎至今沿用
1543
近代初期
哥白尼
Nicolaus Copernicus
日心說 (Heliocentric Model)
太陽為宇宙中心，行星繞太陽做圓形運動；地球自轉解釋晝夜，公轉解釋四季。《天體運行論》推翻托勒密體系。
 ~ 修正
核心正確；圓形軌道被克卜勒橢圓修正；「宇宙中心」在現代宇宙學中不成立
1600
近代初期
吉爾伯特
William Gilbert
地磁學 / 靜電與磁力之區分
地球本身是巨大磁鐵；首創 "electricus"（電）一詞；區分靜電吸引與磁力。《論磁》。
 ✓ 仍有效
地球磁場理論成立，近代地磁學基礎
1609–1619
近代初期
克卜勒
Johannes Kepler
克卜勒行星運動三大定律
①橢圓軌道定律 ②等面積定律（角動量守恆） ③週期定律 T² ∝ a³。純描述性規律，無力學解釋。
 ✓ 仍有效
完全成立；可由牛頓萬有引力推導
1589–1638
近代初期
伽利略
Galileo Galilei
自由落體定律 / 慣性原理 / 斜面實驗
無空氣阻力時所有物體以相同加速度 g 落下；斜面實驗建立運動學方程；提出慣性概念；望遠鏡天文觀測支持日心說。
 ✓ 仍有效
被牛頓力學納入；近代實驗科學方法奠基者
1644
近代初期
托里切利
Evangelista Torricelli
大氣壓力 / 托里切利真空
水銀氣壓計實驗證明大氣壓存在，1 atm ≈ 76 cmHg；推翻「自然厭惡真空」說。
 ✓ 仍有效
完全成立，氣壓計原理至今沿用
1660s
近代初期
虎克
Robert Hooke
虎克定律 (Hooke's Law)
彈力與形變成正比：F = −kx，在彈性限度內成立。顯微鏡觀察，《微觀圖》。
 ✓ 仍有效
彈性限度內完全成立，彈性力學核心
1687
古典力學
牛頓
Isaac Newton
牛頓運動三大定律 / 萬有引力定律
①慣性定律 ②F = ma ③作用力與反作用力。萬有引力：F = Gm₁m₂/r²。微積分（與萊布尼茲共同發展）。光的粒子說。《自然哲學的數學原理》。
 ~ 修正
低速弱重力場完全成立；高速→狹義相對論；強重力→廣義相對論。光粒子說→波粒二象性（量子力學）
1733–1785
古典力學
庫侖
Charles-Augustin de Coulomb
庫侖定律 (Coulomb's Law)
兩點電荷間靜電力：F = kq₁q₂/r²，形式與萬有引力相似。扭力秤實驗。確立電荷守恆概念。
 ✓ 仍有效
古典電磁學完全成立；量子電動力學中仍是重要近似
1798–1800
古典力學
卡文迪什
Henry Cavendish
萬有引力常數 G 之測定
扭力秤實驗首次精確測量 G ≈ 6.674 × 10⁻¹¹ N·m²/kg²，推算地球質量與密度。
 ✓ 仍有效
完全成立，G 值測定方法至今沿用
1800
古典力學
伏打
Alessandro Volta
伏打電池 / 電動勢概念
發明第一個化學電池（伏打電堆），提供穩定電流；建立電動勢 (EMF) 概念。單位「伏特 (V)」以其命名。
 ✓ 仍有效
電位差概念完全成立，電化學基礎
1820
電磁場論
厄斯特
Hans Christian Ørsted
電流磁效應
發現通電導線使周圍指南針偏轉，首次證明電流能產生磁場。打破電與磁獨立的傳統觀念，開啟電磁學統一之路。
 ✓ 仍有效
完全成立，電磁學統一的實驗起點
1820
電磁場論
安培
André-Marie Ampère
安培定律 / 安培力 / 安培右手定則
兩平行電流間磁力定律；電流產生磁場的積分形式（安培定律）；「分子電流」假說解釋物質磁性。
安培右手定則：右手握住導線，拇指指向電流方向，四指彎曲方向即為磁場環繞方向；適用於直線電流與螺線管磁場方向判斷。
✓ 仍有效
安培定律完全成立；馬克士威加入位移電流項推廣為廣義安培定律。右手定則為實用判斷工具，完全有效
1821–1826
電磁場論
歐姆
Georg Simon Ohm
歐姆定律 (Ohm's Law)
V = IR，建立電壓、電流、電阻關係。電路分析基礎。
 ✓ 仍有效
線性電阻材料完全成立；非線性元件（二極體等）不適用
1831
電磁場論
法拉第
Michael Faraday
電磁感應 / 感應電流 / 法拉第電磁感應定律 / 場的概念
電磁感應（感應電流）：變化的磁通量在閉合迴路中產生感應電流，感應電流方向由冷次定律決定。
法拉第電磁感應定律：感應電動勢大小正比於磁通量的變化率：ε = −dΦ/dt（負號體現冷次定律）。
提出「電場」與「磁場」場線概念；電解定律（法拉第電解第一、二定律）。
✓ 仍有效
完全成立，發電機原理基礎。「場」概念被馬克士威數學化
1834
電磁場論
冷次
Heinrich Friedrich Emil Lenz
冷次定律 (Lenz's Law)
感應電流所產生的磁場，方向必定與引起感應的磁通量變化相反，即感應電流的效果阻礙磁通量的變化。
 ✓ 仍有效
完全成立，為能量守恆在電磁感應中的體現
1842–1847
電磁場論
焦耳 / 邁爾 / 亥姆霍茲
Joule / Mayer / Helmholtz
能量守恆定律（熱力學第一定律）
能量不能被創造或消滅，只能轉換形式。焦耳熱功當量實驗測定機械功與熱的等價性。
 ~ 修正
古典範圍完全成立；相對論擴展為質能守恆 E = mc²
1864–1873
電磁場論
馬克士威
James Clerk Maxwell
馬克士威方程式 / 電磁波理論
四方程式統一電磁場：①高斯電場定律 ②高斯磁場定律（無磁單極）③法拉第定律 ④廣義安培定律（含位移電流 ∂D/∂t）。
由此預測電磁波速度 c = 1/√(ε₀μ₀) = 光速，提出光是電磁波。《電磁通論》(1873)。
~ 修正
古典電磁學完全成立；以太假設被推翻；量子電動力學 (QED) 為更深層理論，但馬克士威方程式仍極精確。無磁單極假設尚未被推翻
